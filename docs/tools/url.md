# URL Encode

Encode and decode URL-encoded strings (percent-encoding).

## How to use

1. Enter a URL or query string.
2. Switch between **Encode** and **Decode**.
3. Copy the result.

## Example

| Decoded | Encoded |
|---------|---------|
| `hello world` | `hello%20world` |
| `a=1&b=2` | `a%3D1%26b%3D2` |

## Use cases

- Debug query parameters
- Prepare strings for HTTP requests
- Decode encoded URLs from logs
