# Base64

Encode and decode Base64 strings.

## How to use

1. Paste plain text to **encode**, or a Base64 string to **decode**.
2. Toggle between Encode and Decode modes.
3. Copy the result.

## Example

| Plain text | Base64 |
|------------|--------|
| `Hello` | `SGVsbG8=` |

## Tips

- Paste a Base64-looking string anywhere in the app to auto-open this tool.
- UTF-8 text is supported for encoding and decoding.
