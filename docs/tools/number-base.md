# Number Base

Convert numbers between binary, octal, decimal, and hexadecimal.

## How to use

1. Enter a number in any supported base.
2. Select the input base.
3. View conversions in all other bases instantly.

## Example

| Decimal | Binary | Hex |
|---------|--------|-----|
| `255` | `11111111` | `FF` |

## Tips

- Invalid digits for the selected base show an error.
- Useful for low-level debugging and bitmask work.
