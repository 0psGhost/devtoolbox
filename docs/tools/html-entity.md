# HTML Entities

Encode and decode HTML entities.

## How to use

1. Enter text with special characters (or encoded entities).
2. Choose **Encode** or **Decode**.
3. Copy the output.

## Example

| Plain | Encoded |
|-------|---------|
| `<div>Tom & Jerry</div>` | `&lt;div&gt;Tom &amp; Jerry&lt;/div&gt;` |

## Use cases

- Sanitize text for HTML output
- Decode entities from scraped or logged HTML
