# Text Diff

Compare two text blocks side by side.

## How to use

1. Paste the **original** text in the left panel.
2. Paste the **modified** text in the right panel.
3. Added, removed, and unchanged lines are highlighted.

## Use cases

- Compare config file versions
- Review code or log changes
- Verify before/after transformations

## Tips

- Works line-by-line; best for structured text.
- Empty panels show no diff until both sides have content.
