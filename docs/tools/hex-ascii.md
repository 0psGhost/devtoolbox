# Hex ↔ ASCII

Convert between hexadecimal and ASCII text.

## How to use

1. Enter hex bytes (with or without spaces/colons) or ASCII text.
2. Select **Hex → ASCII** or **ASCII → Hex**.
3. Copy the result.

## Example

| ASCII | Hex |
|-------|-----|
| `Hello` | `48 65 6C 6C 6F` |

## Tips

- Non-printable characters are shown in hex output.
- Useful for debugging binary protocols and packet dumps.
