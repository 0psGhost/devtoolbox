# JSON Formatter

Format, validate, minify, and inspect JSON.

## How to use

1. Open **JSON Formatter** from the sidebar.
2. Paste or type JSON in the input area.
3. The tool validates syntax and shows formatted output automatically.

## Features

- **Pretty-print** with indentation
- **Minify** to a single line
- **Syntax validation** with error messages on invalid JSON
- **Copy** formatted output to clipboard

## Example

Input:
```json
{"name":"DevToolbox","tools":22}
```

Output (formatted):
```json
{
  "name": "DevToolbox",
  "tools": 22
}
```

## Tips

- Paste JSON anywhere in the app to auto-open this tool.
- Large payloads are handled entirely in the browser.
