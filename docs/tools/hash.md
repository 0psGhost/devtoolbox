# Hash Generator

Generate cryptographic hashes from text input.

## Supported algorithms

- MD5
- SHA-1
- SHA-256
- SHA-384
- SHA-512

## How to use

1. Enter or paste text.
2. Select one or more algorithms.
3. Copy any hash from the results.

## Security note

MD5 and SHA-1 are **not** suitable for password storage or security-critical use. Use SHA-256 or stronger for integrity checks. All hashing runs locally in your browser.

## Use cases

- Verify file or string integrity
- Generate test fixtures
- Debug API signature inputs
